# Machine Learning & Pattern Recognition Pipeline (TDS-3)

> [!NOTE]
> **Archived Academic Project**  
> This repository is a read-only historical archive of coursework developed for academic evaluation.

## Overview
This repository contains the laboratory project for the **Tratamiento Digital de Señales 3** (Signal Processing III) course at **Universidad de Antioquia**. The project implements a complete pattern recognition and machine learning pipeline applied to biomedical / time-series signal data.

## Pipeline Architecture
1. **`00_database_article`**: Reference database extraction, metadata definitions, and dataset grounding.
2. **`01_preprocessing`**: Raw signal cleaning, digital bandpass filtering, baseline wander removal, and segmentation.
3. **`02_features`**: Time-domain, frequency-domain (spectral power), and wavelet-based feature extraction.
4. **`03_classification`**: Supervised pattern recognition models, hyperparameter cross-validation, and confusion matrix performance evaluation.
